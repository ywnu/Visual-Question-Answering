# بيادر — واجهة الموقع وإمكانية الوصول (Frontend & Accessibility)

## المطلوب منك
تصميم وتطوير **موقع يعمل فعلًا** ويخدم المكفوفين وضعاف البصر، بحيث يستطيع المستخدم رفع صورة وكتابة سؤال ثم إرسال الطلب ورؤية/سماع الإجابة عند تفعيل القراءة الصوتية. يجب عرض حالة الانتظار والأخطاء بوضوح، ودعم التنقل بالكيبورد، وتسمية الحقول بشكل صحيح، وإظهار مؤشر التركيز، وتوفير تباين ألوان مناسب، وإعلان النتائج لقارئ الشاشة مثل `aria-live`. القراءة الصوتية إضافة اختيارية بعد نجاح عرض الإجابة النصية.

## الربط مع حنان
ارسلي الصورة والسؤال عبر `FormData` إلى `POST /api/answer` بحقلين `image` و`question`. استقبلي `{"answer":"..."}` للنتيجة أو `{"error":"..."}` للخطأ. اتفقي مع حنان على عنوان الـAPI وCORS والاستضافة. يمكن تجربة واجهة بـMock واضح ومؤقت، ولا يُعتبر هذا الموقع النهائي.

## الأدوات والبيانات المطلوبة
HTML وCSS وJavaScript أو تقنية تتفقون عليها، وصورة JPG صغيرة للاختبار. **لا تحتاجين تحميل بيانات Training أو Validation ولا آلاف الصور**.

## التسليم المطلوب
ملفات `frontend/` مع طريقة تشغيل واضحة، وتجربة رفع صورة وإرسال سؤال وعرض الإجابة الحقيقية من الـBackend، واختبار الواجهة على الجوال والكمبيوتر وباستخدام الكيبورد وقارئ الشاشة. لا نعتبر الموقع منشورًا إلا بعد تجربة رابط الاستضافة.

## معلومات مشتركة عن المشروع
المشروع عبارة عن موقع فعّال لمساعدة المكفوفين وضعاف البصر: يرفع المستخدم **صورة** ويكتب **سؤالًا**، فيُرجع نموذج VQA **إجابة نصية فعلية**. نموذج Logistic Regression الموجود في `main.py` يصنّف قابلية الإجابة فقط، وليس النموذج النهائي.

**الفريق:** أسيل (البيانات)، جمانه (نموذج VQA)، ديم (التدريب والتقييم)، حنان (الخلفية والربط)، بيادر (الواجهة وإمكانية الوصول).

**طريقة العمل:** كل بنت تشتغل على Branch المخصص لها وتفتح Pull Request للمراجعة قبل الدمج في `main`. لا ترفعن الصور الكبيرة أو ملفات ZIP أو أوزان النماذج أو المفاتيح السرية أو مجلد `.venv` إلى GitHub. لا تعدّلن `main.py` القديم بدون اتفاق.
