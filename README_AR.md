# ديم — تدريب النموذج وتقييمه (Model Training & Evaluation)

## المطلوب منك
تتعاونين مع جمانه في تقييم إجابات VQA وتحسين النموذج، وتنفذين تقييمًا قابلًا للتكرار على بيانات Validation. قارني إجابة النموذج مع **الإجابات البشرية المرجعية كلها** باستخدام مقياس مناسب لـVQA، وحللي الأخطاء وحالات الصور غير الواضحة وسرعة الاستجابة. إذا كانت متطلبات المادة والجهاز تسمح، شاركي في مقارنة النماذج أو التدريب والتحسين ووثقي الإعدادات والنتائج الفعلية.

## البيانات المطلوبة
`val.json` وصور Validation من [VizWiz](https://vizwiz.org/tasks-and-datasets/vqa/)، وملف تجهيز البيانات من أسيل، وتوقعات أو دالة النموذج من جمانه. **لا تستخدمي Validation للتدريب**.

## تجربة Lab 4 الموجودة
داخل Branch حقك ملف `experiments/compare_answerability_models.py` يقارن Logistic Regression مع Linear SVM باستخدام TF-IDF وأسئلة `data/train.json`. شغليه محليًا وسجلي النتائج الحقيقية. انتبهي: هذه مقارنة **تصنيف قابلية الإجابة فقط** وليست تقييمًا لإجابات VQA النهائية.

## التسليم المطلوب
كود تقييم يمكن إعادة تشغيله، جدول نتائج حقيقية ومقارنة النماذج، رسومات، أمثلة أخطاء واستنتاجات مختصرة، وتوضيح ما تم تدريبه فعليًا وما كان جاهزًا مسبقًا.

## معلومات مشتركة عن المشروع
المشروع عبارة عن موقع فعّال لمساعدة المكفوفين وضعاف البصر: يرفع المستخدم **صورة** ويكتب **سؤالًا**، فيُرجع نموذج VQA **إجابة نصية فعلية**. نموذج Logistic Regression الموجود في `main.py` يصنّف قابلية الإجابة فقط، وليس النموذج النهائي.

**الفريق:** أسيل (البيانات)، جمانه (نموذج VQA)، ديم (التدريب والتقييم)، حنان (الخلفية والربط)، بيادر (الواجهة وإمكانية الوصول).

**طريقة العمل:** كل بنت تشتغل على Branch المخصص لها وتفتح Pull Request للمراجعة قبل الدمج في `main`. لا ترفعن الصور الكبيرة أو ملفات ZIP أو أوزان النماذج أو المفاتيح السرية أو مجلد `.venv` إلى GitHub. لا تعدّلن `main.py` القديم بدون اتفاق.
