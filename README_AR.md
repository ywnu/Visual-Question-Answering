# جمانه — تطوير نموذج VQA

## المطلوب منك
بناء الجزء الأساسي: **صورة + سؤال باللغة الإنجليزية ← إجابة نصية فعلية**. ابدئي بتجربة استدلال واحدة حقيقية باستخدام صورة JPG وسؤال، ثم اختاري نموذج رؤية ولغة مناسبًا لمواصفات الجهاز وشروط المادة والترخيص. اكتبي `src/vqa_model.py` بدالة مثل `answer_question(image: PIL.Image.Image, question: str) -> str` لتستخدمها حنان. سجلي اسم النموذج وإصداره، خطوات المعالجة، سرعة الاستجابة، وأي أخطاء. نسّقي مع ديم بخصوص التدريب أو Fine-tuning. لا تصفي النموذج بأنه مُدرَّب منكم إذا استخدمتم نموذجًا جاهزًا للاستدلال فقط.

## البيانات والبرامج المطلوبة
استفيدي من البيانات التي تجهزها أسيل، ومعها ملفات VizWiz المحلية (الصور و`train.json` و`val.json`) من [المصدر الرسمي](https://vizwiz.org/tasks-and-datasets/vqa/). قد تحتاجين Pillow وPyTorch وTransformers وفق النموذج المختار. لا تحملين أوزان نموذج كبير قبل التأكد من توافقه مع الجهاز، ولا ترفعين الأوزان على GitHub.

## التسليم المطلوب
دالة قابلة للاستخدام، وتعليمات تثبيت وتشغيل، وتجربة فعلية تُظهر الصورة والسؤال وإجابة النموذج، وملاحظات عن زمن الاستجابة واستهلاك الموارد، وعقد ربط واضح مع حنان. يكتمل الجزء عند إنتاج **الإجابة نفسها** وليس فقط Answerable أو Unanswerable.

## معلومات مشتركة عن المشروع
المشروع عبارة عن موقع فعّال لمساعدة المكفوفين وضعاف البصر: يرفع المستخدم **صورة** ويكتب **سؤالًا**، فيُرجع نموذج VQA **إجابة نصية فعلية**. نموذج Logistic Regression الموجود في `main.py` يصنّف قابلية الإجابة فقط، وليس النموذج النهائي.

**الفريق:** أسيل (البيانات)، جمانه (نموذج VQA)، ديم (التدريب والتقييم)، حنان (الخلفية والربط)، بيادر (الواجهة وإمكانية الوصول).

**طريقة العمل:** كل بنت تشتغل على Branch المخصص لها وتفتح Pull Request للمراجعة قبل الدمج في `main`. لا ترفعن الصور الكبيرة أو ملفات ZIP أو أوزان النماذج أو المفاتيح السرية أو مجلد `.venv` إلى GitHub. لا تعدّلن `main.py` القديم بدون اتفاق.
