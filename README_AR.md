# حنان — Backend, API & Integration

## مهامك
إنشاء API للإجابة وربط نموذج جمانه، ثم التكامل مع الواجهة والصوت عند الحاجة.

## البيانات والأدوات المطلوبة
Flask وPillow ودالة النموذج وصورة اختبار؛ لا تحتاج جميع صور الداتا.

## المطلوب تسليمه
واجهة GET /api/health وPOST /api/answer للصورة والسؤال، واستجابة answer/error واختبارات.

## نطاق المشروع والأولويات المتفق عليها
**P0 — أساسي: موقع VQA بالعربي والإنجليزي.** يرفع المستخدم صورة ويسأل كتابة بأي من اللغتين، فيحصل على **إجابة حقيقية يولدها النموذج** وتظهر بالمحادثة. لازم يكون الموقع متكاملًا ويعمل من البداية للنهاية.

**P1 — أساسي: المحادثة الصوتية.** يتكلم المستخدم فيتحول سؤاله إلى نص، ثم يسمع رد الذكاء الاصطناعي صوتيًا، **بالعربي والإنجليزي**. دعم المتصفحات لتحويل الصوت يختلف، لذلك نختبره مبكرًا ونجهز بديلًا عند الحاجة. نحتاج إذنًا واضحًا للميكروفون، وموقع HTTPS، وتجربة مناسبة لقارئ الشاشة ورسائل الأخطاء.

**P2 — اختياري بعد اكتمال الأساسيات: الكاميرا المباشرة.** نبدأ بمعاينة الكاميرا والتقاط إطار عند السؤال؛ تحليل فيديو مستمر مثل مكالمة حقيقية أصعب وليس شرطًا للتسليم. لا نؤخر P0/P1 بسببه.

**اتفاق الربط:** `POST /api/answer` يستقبل صورة في `image` وسؤالًا في `question` بصيغة multipart ويعيد `{"answer":"..."}` أو `{"error":"..."}`، و`GET /api/health` يعيد `{"status":"ok"}`. هذه **واجهة متفق عليها للتطوير ولم تُشغّل بعد**. يمكن بدء خدمة التعرف على الصوت وقراءته من المتصفح، ثم تحويلها إلى خدمة خلفية إذا احتجنا.
